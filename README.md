# Launchpad Startup Manager — Downloads

Download the latest version from [Releases](https://github.com/stefanr201/launchpad-startup-manager-releases/releases/latest).

Each release contains:

- `Launchpad-Setup-<version>-win-x64.exe` — install for your Windows account. It adds a Start Menu shortcut and appears in Installed Apps so you can update or uninstall it normally. A Start Menu uninstall shortcut is included too.
- `Launchpad-portable-<version>-win-x64.zip` — extract and run `Startup Manager.exe` without installing.
- **SHA256SUMS.txt** — SHA-256 hashes for the installer and portable package.

Launchpad is a 64-bit Windows desktop app. Its source is maintained in a separate private repository.
